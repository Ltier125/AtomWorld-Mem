Overview

The missing state is memory

Similar atomic snapshots can hide different dynamical histories, future-event preferences, and waiting-time scales.

Abstract

AtomWorld-Mem treats long-horizon atomistic evolution as a memory-based world-state restoration problem. Multi-scale spatial encoders write atomistic keyframes from dense local topology and sparse long-range defect context. Short-term event memory and long-term structural memory integrate these keyframes over time, restoring a future-predictive latent state missing from any instantaneous crystal snapshot.

The restored state prioritizes only simulator-provided legal vacancy-mediated events. Event legality, atomic execution, and KMC residence-time updates remain governed by the underlying simulator. Under matched microscopic event budgets, the model improves structural progress while retaining agreement with reference energetic, structural, and vacancy-transport trends.

Restore hidden context

Recover recent transition competition and slower structural trends that cannot be inferred from the current snapshot alone.

Stay inside the legal event set

Rank physically admissible vacancy exchanges rather than generating unconstrained atomic moves.

Preserve the KMC clock

Advance physical time using standard residence-time increments computed from the simulator's base rates.

Architecture

Four coupled modules

Space writes high-information keyframes; memory turns partial observations into a future-predictive state.

01

Keyframe Writer

Encodes a vacancy-centered graph over structured 1NN-4NN shells and combines it with sparse long-range defect tokens. The fused keyframe is a spatial write into memory, not a complete dynamical state.

02

Latent-State Memory

Short-term memory summarizes recent vacancy motion, reversibility, and event competition. Recurrent long-term memory accumulates aggregation tendency, defect evolution, and structural bias.

03

Legal Event Scorer

Scores each admissible event from its local structure, hop direction, and energetic or kinetic features, conditioned on the restored state and fused with KMC and energy priors.

04

Physics-Guided Policy Learner

Uses recurrent PPO, a soft physics teacher, and event-time consistency to improve long-horizon progress without leaving the simulator-defined legal action space.

One restored state, two coupled predictions

The memory-conditioned hazard field determines both legal-event preference and an expected waiting-time readout. AtomWorld-Mem does not replace the KMC clock: the executed residence-time increment still comes from the sum of base legal-event rates at each visited state.

Interpretation

Physical scope and limitations

What is preserved

  • Simulator-defined legal vacancy exchanges
  • Atomic updates executed by the KMC environment
  • Residence-time increments computed from base KMC rates
  • Checks across energetic, structural, and transport observables

What is not claimed

  • The learned policy intentionally biases event selection
  • It is not an exact replacement for passive KMC path sampling
  • Detailed balance and the unbiased path measure are not guaranteed
  • Current experiments focus on vacancy-mediated BCC alloys
